# 101 — мобильная карточная игра

HTML5-игра «101» (похожа на UNO, играется колодой в 36 карт). Русский интерфейс. Два режима: против ботов (офлайн) и с людьми — P2P-лобби по коду комнаты (PeerJS/WebRTC, сервер не нужен). Ставится на телефон как приложение (PWA).

## Запуск

Открой `index.html` в браузере. Игра с ботами работает полностью офлайн; для игры с людьми нужен интернет (соединение устанавливается напрямую между телефонами через бесплатный публичный сигнальный сервер PeerJS).

## Общение за столом

Кнопка 😊 в игре открывает панель стикеров. Стикер всплывает пузырём над твоим аватаром у всех за столом (антиспам 1.5 сек). Стикеры бывают двух видов:

- **Встроенные** — картинки из папки `stickers/` проекта. Чтобы поменять набор: положи/замени там свои PNG/JPG (имена файлов задают порядок: 01.png, 02.png, …), выполни `node build.js` — они сожмутся до 96×96 и вошьются в игру, после перезаливки index.html будут у всех игроков.
- **Личные** — добавляются кнопкой «+» прямо в игре: картинка с телефона обрезается в квадрат и хранится на устройстве (до 20 штук), удаляется крестиком.

Кнопка «←» в углу — выход из игры: у гостя место занимает бот, выход хоста завершает игру для всех.

## Игра с людьми

1. Один игрок жмёт «Играть с людьми» → «Создать лобби» и получает код из 4 символов.
2. Остальные жмут «Войти», вводят код — и попадают в комнату (2–5 мест, можно докинуть ботов).
3. Хост нажимает «Начать игру». Игру «судит» телефон хоста; если гость отключился — его доигрывает бот.

## Как выложить игру и установить на телефоны

Проще всего — GitHub Pages (бесплатно):

1. Залей в репозиторий на GitHub файлы: `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`.
2. В настройках репозитория: Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
3. Через минуту игра будет по адресу `https://<твой-ник>.github.io/<имя-репозитория>/` — эту ссылку кидаешь друзьям.

Установка на телефон:
- **iPhone**: открыть ссылку в Safari → кнопка «Поделиться» → «На экран "Домой"». Появится иконка, игра запускается на весь экран как приложение.
- **Android**: открыть ссылку в Chrome → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Готовая игра одним файлом (шаблон + движок + peerjs, собирается `build.js`) |
| `engine.js` | Игровой движок: чистая логика без UI, работает и в Node.js. Action-based API (`getLegalActions` / `applyAction`) — на нём же построен P2P-мультиплеер |
| `ui.template.html` | Шаблон интерфейса (на места `//__ENGINE__//` и `//__PEERJS__//` вставляются движок и библиотека) |
| `build.js` | Сборка: `npm install` (один раз), затем `node build.js` → обновляет `index.html` |
| `test.js` | Автотесты: `node test.js` — юнит-тесты правил + 300 полных симуляций игр ботами |
| `manifest.json`, `sw.js`, `icon-*.png` | PWA: установка на телефон и офлайн-кэш |
| `smoke*.js` | Смоук-тесты UI через Playwright (нужен `npm i playwright`), включая мок-тест мультиплеера |

Мультиплеер устроен так: хост создаёт комнату с id `durak101-room-<код>` в PeerJS, гости подключаются напрямую (WebRTC). Движок игры выполняется только у хоста; гости отправляют действия (`{t:'act'}`), хост валидирует их и рассылает всем полное состояние (`{t:'state'}`) со своим номером места для каждого. Анимации и тосты у гостей строятся по разнице журнала событий `state.log`.

## Правила

- Колода 36 карт, раздача по 5, следующая карта открывается на стол.
- Ходы по часовой стрелке. Закрыть верхнюю карту можно картой той же масти или того же значения.
- Нечем ходить — берёшь одну карту из колоды (если подошла, можно сразу сыграть).
- Колода закончилась — карты со стола (кроме верхней) перемешиваются в новую колоду.
- Победил в раунде тот, кто первым остался без карт.

### Эффекты карт

| Карта | Эффект | Очки |
|---|---|---|
| 6 | Закрой её сам — или возьми одну карту из колоды, или спасуй (выбор всегда есть) | 6 |
| 7 | Следующий берёт +2 карты; семёрки стакаются (до +8), отбиться можно своей семёркой | 7 |
| 8 | Нужно самому закрыть её; брать из колоды можно всегда, даже имея чем закрыть | 8 |
| 9 | Следующий игрок обязан закрыть её; брать из колоды можно всегда, даже имея чем закрыть | 0 |
| 10 | — | 10 |
| Валет | — | 2 |
| Дама | Кладётся по обычным правилам совпадения, после чего меняет масть. Закрыл раунд дамой — всем проигравшим +40 очков | 3 |
| Король | — | 4 |
| Туз | Шаг назад: ход переходит предыдущему игроку, дальше по часовой. Когда игроков осталось двое — даёт дополнительный ход (нечем ходить — берёшь карту из колоды как обычно) | 11 |

Взять карту из колоды можно всегда, даже если есть чем ходить (одну за ход). Если взятая карта подходит — её можно сразу сыграть.

Принудительный добор (после 8 и 9) идёт по одной карте за нажатие — до упора. Только штраф за семёрки берётся сразу пачкой.

Если игрок вышел девяткой (последняя карта требует закрытия), раунд не заканчивается, пока следующий игрок её не закроет — добранные при этом карты идут ему в счёт.

Новый раунд открывает последняя карта победителя прошлого раунда, и её модификаторы действуют: семёрка — первый игрок под штрафом +2, девятка — первый игрок закрывает её, туз — ход уходит назад от победителя (при двух игроках — дополнительный ход победителю), дама — задаёт свою масть. Победителю при этом раздаётся только 4 карты — его пятая уже лежит на столе. В первом раунде всё то же самое, только «владелец» стартовой карты случайный: раздача начинается с игрока после него, последняя разданная карта идёт на стол, и её модификаторы тоже действуют.

После окончания игры кнопки «Играть ещё» и «Перемешать игроков» запускают новую партию тем же составом (во втором случае — со случайной рассадкой) — в мультиплеере лобби пересоздавать не нужно, гости просто ждут хоста.

### Очки и вылет

- В конце раунда все, кроме победителя, суммируют очки карт в руке.
- Сумма по всем раундам **больше 101** — игрок вылетает.
- **Ровно 101** — очки аннулируются (обнуляются).
- Победитель игры — последний оставшийся игрок.
- Первым в новом раунде ходит игрок после победителя прошлого раунда (в первом раунде — случайный).

### Принятые допущения (в правилах не уточнялось)

- После взятия штрафа за семёрки ход пропускается.
- Взял карту на обычном ходу — если она подходит, можно сыграть её или спасовать; не подошла — ход переходит.
- Если победный (последний) сыгранный в раунде картой оказалась семёрка — следующий игрок берёт штраф до подсчёта очков.
- Спасовать после своей шестёрки можно и когда она — последняя карта (это победа); после 8 пас недоступен, пока есть чем закрыть или что добирать.
